2. WordPress.com पर website बनाना

  1. WordPress.com account में login करें और Games Planet नाम से site बनाएं।
  2. Custom theme और अपना domain लगाने के लिए paid plan चाहिए। Official support के अनुसार Personal, Premium, Business और Commerce plans custom theme uploads और plugins support करते हैं। अपने account में Upload Theme उपलब्ध होना check करें। सिर्फ WhatsApp enquiry store के लिए Commerce plan लेना जरूरी नहीं है। Paid plan की खरीदारी आप स्वयं करें।
  3. Dashboard → Appearance → Themes → Add Theme / Install new theme → Upload Theme खोलें। GamesPlanet-WordPress-Theme.zip चुनें → Install Now → Activate।
  4. Theme activate होने के बाद homepage पर GitHub से तैयार किया हुआ product catalog दिखेगा। Homepage काम करने के लिए CSV import जरूरी नहीं है।
  5. Settings → General में site title Games Planet और timezone Kolkata सेट करें। Site को अभी private/Coming Soon रखकर जाँच लें।

3. GoDaddy से gamesplanet.in जोड़ना

  1. GoDaddy → My Products / Domain Portfolio में gamesplanet.in खोजें। Domain active और आपके control में होना चाहिए। अगर expired दिखे तो पहले GoDaddy में renew करें। अगर list में न मिले, खरीदने के समय वाला account/email खोजें या GoDaddy support से ownership recover करें।
  2. WordPress.com Hosting Dashboard → अपनी Games Planet site → Domains → Add domain name → Use a domain name I own।
  3. gamesplanet.in डालें → Continue → Connect your domain name to this site चुनें। Transfer वाला विकल्प जरूरी नहीं है।
  4. Start setup / Domain Connect मिले तो उसे चुनें → GoDaddy में login → Connect। यह सबसे सीधा तरीका है।
  5. Automatic setup न मिले तो GoDaddy Domain Portfolio में domain चुनें → Nameservers → I’ll use my own nameservers। नीचे दिए WordPress.com nameservers डालें और Save करें। पुराने nameservers हटाकर केवल ये तीन रखें।

अगर domain पर business email चलता है, nameserver बदलने से पहले MX, SPF, DKIM, DMARC और जरूरी verification records का record रखें और WordPress.com DNS में वही records बनाएँ। वरना email रुक सकता है। पुराने hosting IP को WordPress.com nameservers के साथ mix न करें।
  1. WordPress.com Domains में status Active होने और SSL certificate आने का इंतजार करें। सामान्यतः कुछ घंटे लगते हैं; DNS update को 72 घंटे तक लग सकते हैं।
  2. Domain active होने पर gamesplanet.in को Primary domain बनाएं। www.gamesplanet.in भी check करें; दोनों से एक ही primary address खुले।
  3. Phone के mobile data पर HTTPS website खोलकर homepage, category, cart और WhatsApp enquiry check करें। इसके बाद site को public/launch करें।

4. Products dashboard से edit करने हैं तो

यह optional है। Bundled catalog अपने आप GitHub से live sync नहीं होता। आगे के edits के लिए WooCommerce को central catalog बनाया जा सकता है।

  1. Theme activate करें और पहले gamesplanet.in domain + SSL connect करें। CSV के image URLs इसी domain पर theme की assets से import होते हैं।
  2. Plugins → Add New → WooCommerce → Install → Activate। Store country India, currency INR, weight unit g, dimensions cm रखें। Payment gateway या paid extension लेने की जरूरत इस WhatsApp enquiry flow में नहीं है।
  3. Products → All Products → Import → GamesPlanet-WooCommerce-Products.csv चुनें। पहली import में Update existing products unchecked रखें।
  4. Column mapping review करें। Weight (g) को Weight और dimensions को सही fields से map करें। Meta: gp_shop_page, Meta: gp_custom_type, Meta: gp_selector_url, Meta: gp_video_url को meta import से map करें, अगर स्वतः map न हों।
  5. Run importer और completion report देखें। CSV में 273 parent products और 22 variation rows हैं। किसी image/row पर error आए तो उसे ठीक करें; import पूरी होने तक नीचे वाला switch न बदलें।
  6. Appearance → Customize → Games Planet catalog → Use WooCommerce products enable → Publish। अब storefront के नाम, prices, photos और variants WooCommerce से आएँगे।
  7. Products में price/photo/description/stock edit करें → Update। नई product की custom field gp_shop_page नीचे दी category keys में से रखें। Field खाली होने पर product Gaming accessories में दिखाई देगा।

Category keys: consoles, ps2, ps3, ps4, ps5, arcade, arcade-box, cpu, gamebox, gaming, mobile, coolers, cables, electrical, batteries, decoration

5. Orders कैसे आते हैं?

Customer categories से products एक shopping bag में रखेगा → name, 10-digit mobile, address, PIN code भरेगा → Review on WhatsApp दबाएगा → WhatsApp में message review करके खुद Send करेगा। Message Games Planet के 7983624797 पर जाएगा। Customer number में +91 input हो तो enquiry output में सिर्फ 10 digits रखे जाते हैं।

यह payment gateway checkout या automatic confirmed order system नहीं है। Delivery charge, availability और payment आप WhatsApp पर confirm करेंगे। इस enquiry bag से WooCommerce Orders में automatic record नहीं बनता। पुराने PS2/CPU/arcade builders और game selectors अपने original GitHub pages पर खुलते हैं; builders का cart अलग रहता है।

6. GitHub पर क्या करना है?

Requested repository: gamesplanet13/gamesplanet.in। Root में static website files और wordpress/ में theme source रखा जा सकता है। GitHub Pages के लिए Settings → Pages → Deploy from a branch → main / root चुनें। Source GitHub में और domain WordPress.com में होने पर GitHub Pages में gamesplanet.in custom domain न लगाएँ। एक ही domain को दो अलग hosting destinations पर एक साथ point न करें।

अगर नई repository बनाने के लिए sign-in पूरा नहीं हुआ है, repository upload pending है। Packaged files तैयार हैं; केवल ZIP होने को GitHub upload न समझें।

7. क्या merge हुआ और क्या जाँचना है?

  • 62 accessible repositories की inventory; 59 non-empty repositories के current fetched snapshots पढ़े गए। 3 repositories empty/no checkout हैं।
  • Primary retail catalog: arcade-accessories-। Products repository के अलग listings जोड़े गए। Older master JSON से exact name match होने पर missing size/weight लिया गया; पुराने prices से current primary prices overwrite नहीं हुए।
  • 273 active listings, 16 category groups। Out-of-stock exclusions original stock rules से रखे गए। 7 exact-name price conflicts audit में दिए हैं; primary catalog rate इस्तेमाल हुआ। Similar names वाले अलग products में manual review अभी जरूरी हो सकता है।
  • नया design latest Chiptrades reference से inspired है: gradient header/buttons, बड़ा product gallery, quantity, variants, specifications, FAQs, related products, saved products और recently viewed। Categories का परिचित flow आपकी पुरानी MyDukaan site से लिया है। Logo और contact details उसी से लिए हैं; promotional panels नए बनाए हैं। Policy links अभी original MyDukaan policy pages पर खुलते हैं। WordPress में Account link WooCommerce active होने पर उपलब्ध होता है; static preview में Support दिखता है।
  • जहाँ exact product photo नहीं मिला, placeholder दिया गया है। किसी दूसरे model की photo invent नहीं की गई। Images optimized WebP में bundled हैं।
  • New storefront में search, sort, details, variants, bag और enquiry form हैं। Existing business tools, selectors और builders hub से link किए गए हैं; उनके backend या order databases migrate नहीं हुए हैं।
  • Browser में full product page, search, quantity, multi-category cart, saved products, variant price/weight और PIN enquiry flow की जाँच हुई। WooCommerce mode में native product URLs पर नया product template भी दिया गया है। WordPress theme/CSV को आपके WordPress.com account में install/import करके end-to-end जाँचना बाकी है।
